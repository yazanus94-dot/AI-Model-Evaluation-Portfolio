AI Model Evaluation Portfolio

Python 3.12MITCI

Honest, tested evaluation tooling: JAX metrics cross-validated against NumPy, SGLang LLM-judge with position-bias control, and a vLLM rubric harness with failure taxonomy. Every project tested with mock backends in CI.

Author: Yazan Aljabari

Projects

jax-eval-metrics

Can evaluation metrics themselves be trusted? JAX implementations of Cohen's kappa, ECE, Brier, bootstrap CIs, every result cross-checked against a plain-NumPy reference.

sglang-judge-pipeline

Can we trust an LLM-as-judge? Pairwise judging with answer-order swapping to control for position bias, constrained decoding, contradiction detection.

vllm-eval-harness

Does a model satisfy a rubric test suite? Severity-weighted scores, deterministic checks, failure taxonomy, flaky-case detection, throughput.

Quick start (no GPU needed)

pip install -r jax-eval-metrics/requirements.txt
cd jax-eval-metrics && python -m pytest -q
cd ../sglang-judge-pipeline && PYTHONPATH=src python -m pytest -q
cd ../vllm-eval-harness && PYTHONPATH=src python -m pytest -q

See the README for full documentation, methodology, results, and limitations.
